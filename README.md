# Сезам

Android-приложение для открытия шлагбаумов звонком: две кнопки в v0, автоподсказка нужного въезда по геолокации и движению — в v1.

Личный проект, ставится сайдлоадом, в Play не публикуется.

- **Версионирование:** [docs/VERSIONING.md](docs/VERSIONING.md) — Semantic Versioning без префикса `v` (тег `0.2.0`, не `v0.2.0`).
- **Техническое задание v0:** [docs/SPEC-v0.md](docs/SPEC-v0.md) — в том числе раздел «Ожидания от v1».
