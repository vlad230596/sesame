# Иконка «Сезам»

Знак — стрела шлагбаума в поднятом положении: барьер уже открыт, что и есть
результат нажатия кнопки. Красно-белые сегменты — стандартная разметка стрелы,
единственная деталь, по которой шлагбаум читается с 48 px.

## Геометрия

Канва adaptive icon — 108×108. Вся графика уложена в окружность r≈31 от центра
(54, 54) при безопасной зоне r=33, поэтому любая маска лаунчера (круг, сквиркл,
скруглённый квадрат) ничего не срезает. Стрела повёрнута на −32° вокруг шарнира
(38, 62), композиция сдвинута на (−1.25, −2) для центровки оптической массы.

## Файлы

| Файл | Назначение |
|---|---|
| `icon.svg` | Собранная иконка под маской — для README, доков, превью |
| `ic_launcher_foreground.svg` | Передний план, 108×108 |
| `ic_launcher_background.svg` | Фон-градиент, 108×108 |
| `ic_launcher_monochrome.svg` | Силуэт для тематических иконок Android 13+ |
| `android/*.xml` | Те же слои как vector drawable, готовые к копированию |

## Установка в проект

Из `android/` скопировать:

- `ic_launcher_foreground.xml`, `ic_launcher_background.xml`,
  `ic_launcher_monochrome.xml` → `app/src/main/res/drawable/`
- `ic_launcher.xml` → `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`
  и туда же копией под именем `ic_launcher_round.xml`

Старые растровые `mipmap-*dpi/ic_launcher.png` из шаблона Android Studio удалить:
minSdk проекта 34, adaptive icon поддерживается везде.
